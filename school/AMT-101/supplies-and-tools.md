# AMT 101: Supplies & Tools

## Calculator: TI-30Xa (Texas Instruments)
- **This is the exact calculator used on our exams.** Highly recommended to get one ([photo](images/2026-10-12-ti-30xa-calculator.jpg)).
- Do **all** homework and practice tests with it so you're fast and comfortable on test day.

### Quick guide to the keys you'll use most
| Task | How on the TI-30Xa | Example |
|---|---|---|
| Clear | `ON/C` | |
| Square a number | number, then `x²` | 12 `x²` → 144 |
| Square root | number, then `√x` (enter the number **first**) | 25 `√x` → 5 |
| Powers | number `yˣ` power `=` | 2 `yˣ` 3 `=` → 8 |
| Pi | `π` | Area of a circle: `π` × 3 `x²` `=` |
| Fractions | `a b/c` between numbers | 3 `a b/c` 8 → 3/8 |
| Fraction ↔ decimal | `2nd` then `a b/c` (F↔D) | 3/8 → 0.375 |
| Reciprocal | number, then `1/x` | Parallel resistors |
| Negative number | number, then `+/-` (not the minus key) | |
| Scientific notation | `EE` | 4.7 `EE` 3 → 4,700 |
| Percent | `2nd` then `5` (%) | |
| Fix a typo | `←` (backspace) | |

**Before every test:** make sure the screen shows **DEG** (degrees mode), not RAD/GRAD. The `DRG` key changes it.

**Where it shows up:** math, physics (pressure, gas laws), electricity (Ohm's law, parallel resistors with `1/x`), and weight & balance (moments and CG).
