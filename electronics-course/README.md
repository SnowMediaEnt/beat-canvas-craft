# Circuits Preflight

A self-contained, interactive electronics refresher course — built as a single
HTML file with no dependencies, no build step, and no network access required.

**To use it:** double-click `index.html` (or drag it onto any browser). That's it.

## What's inside

Seven lessons, each ending in an 8-question quiz (pass at 80%):

1. Charge, current, voltage & power — Ohm's law, units and prefixes
2. Resistors & the color code — interactive band decoder, tolerance, power ratings
3. Series circuits — adding resistance, voltage drops, the voltage divider
4. Parallel circuits — reciprocal rule, current divider, redundancy
5. Series–parallel networks — the reduction method, equivalent-resistance calculator
6. Kirchhoff's laws & the Wheatstone bridge — KCL, KVL, strain-gauge bridges
7. Capacitors, inductors & RC transients — time constants, 400 Hz aircraft power

Quiz scores save automatically in the browser (localStorage), per device.
Retake quizzes freely — the best score is kept. The page follows your system's
light/dark appearance.

Because some hosted viewers clear browser storage between visits, the course
map has a **save code** panel: copy the code (e.g. `s1=100 s2=88`) when you
finish a session, and paste it into any copy of the course — on any device —
to restore your progress.
